# WebApp

This is a basic Spring Boot web application.

## Setup Instructions

1. **Clone the repository:**

   ```bash
   git clone https://github.com/harshal-rembhotkar/DevOps.git
   cd DevOps
   ```

2. **Build the project:**

   Use Maven to build the project:

   ```bash
   mvn clean install
   ```

3. **Run the application:**

   Start the application with:

   ```bash
   mvn spring-boot:run
   ```

4. **Access the application:**

   Once the application is running, open your web browser and go to `http://localhost:8080`.

That's it! The application should be up and running.
